Search the web for remote MCP servers from the home page: type a name instead of a URL and choose **Search the web** (or press `Enter` when no suggestion matches). Results show how each server authenticates, and picking one fills in its URL and any headers it needs for you to complete before connecting. Results come from Exa and need `EXA_API_KEY`. Suggested sources are now built in, so Hookfish no longer needs PGlite or Postgres.
